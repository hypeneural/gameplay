# Gallery native v2 — design and provenance

Original lightweight SVG vectors created for the Estudio Evydencia Christmas gallery (2026-10-08). No client photos, names, orders, private tokens, stock art or third-party fonts are embedded.

## gallery-native-v2

- `gallery-evergreen-header-v1.svg`: transparent decorative pine, warm lights, red ornaments and gold highlights. Used in the gallery intro.
- `gallery-starlight-footer-v1.svg`: light-weight starlight edge decoration for the gallery finale.
- `gallery-snowflake-seal-v1.svg`: decorative snowflake badge below each photo, never covering photo pixels.

These assets are owned by the project, static, responsive, accessible as decorative CSS backgrounds and disabled as interactive media. The review state indicates structurally ready assets, not physical iPhone/Safari visual approval. Runtime policy preserves reduced motion (static SVGs have no animations).

The conceptual design mockup was prepared separately and is not committed because it includes illustrative photographs and UI text, rather than production-ready source assets.
