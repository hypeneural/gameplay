This validation is deliberately scoped to the pinned `phaser@4.2.1` source tag. The public Phaser API website was serving 4.1 material when checked, so it is useful for concepts but not used as the authority for a 4.2.1 call.

## Corrections applied to the prior plan

- Phaser 3 examples remain useful only as conceptual reference. Any Phaser behavior adopted by the Game Factory has a 4.2.1 tagged source above.
- Phaser already coordinates its loop and sound focus behavior. Product run duration must still exclude hidden time, which is why this repository owns a separate active clock.
- A retry count is not a delivery guarantee. Games must expose `GAME_ASSET_RETRY`/`GAME_ASSET_FAILED`, stop after the bounded policy and choose a declared placeholder or retry UI. Puzzle forwards its final required-photo failure through the latter and makes manual retry an explicit player choice.
- Rename is atomic only in the intended same-filesystem publishing path. Cross-volume moves, database status transitions and job leases belong to the future deployment adapter and are not assumed here.
