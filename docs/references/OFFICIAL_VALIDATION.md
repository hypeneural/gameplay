## Corrections to carry forward

- The source material's conclusion about a compact `AGENTS.md` is sound project guidance, but the exact claim of a 100-line official OpenAI recommendation was not independently established by the official page checked. The repository uses a short map as a local design choice.
- The phrase “Phaser official today” is version-sensitive. The repository locks the audited release rather than assuming it will remain latest.
- Nginx `internal` hides direct access to the location; it does not replace application authorization, ID validation, cookie policy or path traversal protection.
