## Descoberta confirmada de Skills

A documentação oficial Build skills confirma que Codex procura Skills de
repositório em .agents/skills, desde o diretório atual até a raiz. Cada Skill
tem SKILL.md com nome e descrição; por isso E1.2 usa duas Skills pequenas
versionadas no repositório, sem depender de plugin instalado.

## Limites importantes

1. O repositório upstream do Game Studio confirma a existência do bundle, não
   sua instalação nesta sessão. Não há dependência oculta dele.
2. Esta descoberta confirma o caminho de repositório, mas não garante que toda
   Skill seja automaticamente apropriada. A descrição precisa ter escopo
   discriminante e a Skill deve passar por validação.
3. Largura × altura × 4 é uma estimativa de textura RGBA decodificada, não uma
   medição universal de GPU. Mipmaps, canvas, implementação do navegador e
   compressão podem alterar o consumo efetivo.
4. Material de Phaser que altera runtime deve seguir a ordem definida em
   AGENTS.md: tag 4.2.1, skill vendorizada, tipos instalados e exemplo oficial
   da mesma versão.
5. Nenhuma fonte externa de arte, áudio ou modelo está aprovada por esta
   validação. A Fábrica de Assets v2 continua responsável por origem, licença,
   hash, preparo e revisão humana.
