# Receita — peça escolhida

| Campo                 | Definição                                                                                              |
| --------------------- | ------------------------------------------------------------------------------------------------------ |
| Finalidade            | Deixar claro qual é a primeira peça de uma troca toque–toque.                                          |
| Planos de cena        | L2, no contorno da célula; nunca como filtro sobre a imagem.                                           |
| Asset aprovado        | Nenhum arquivo adicional; moldura de célula desenhada pelo runtime.                                    |
| Gatilho               | Primeiro toque em uma peça disponível.                                                                 |
| Duração e intensidade | Contraste imediato e elevação de até 140 ms; fica estático até a próxima decisão.                      |
| Foto protegida        | A peça continua visível e proporcional; não há preenchimento opaco sobre a imagem.                     |
| Limite ativo          | Um contorno selecionado e um tween curto.                                                              |
| Som                   | Papel toque ou seleção, curto; borda branca e elevação são a alternativa visual.                       |
| Qualidade             | NORMAL e LOW mantêm a borda; reduzido mantém somente contraste estático.                               |
| Ciclo de vida         | A Scene é dona do tween; selecionar outra peça, cancelar, pausar, sair ou destruir encerra a resposta. |
| Teste de aceite       | A criança identifica a primeira peça em 390 px e consegue cancelar tocando nela de novo.               |

Referências de direção: Bíblia de movimento e dicionário de componentes.
