# Receita — troca correta

| Campo                 | Definição                                                                                             |
| --------------------- | ----------------------------------------------------------------------------------------------------- |
| Finalidade            | Celebrar apenas a peça que acabou de chegar à sua célula resolvida.                                   |
| Planos de cena        | L2 ao redor da borda da célula; pequenas faíscas podem nascer atrás dela em L1.                       |
| Asset aprovado        | Áudio correct já catalogado; faíscas de texto existentes não introduzem arquivo de browser adicional. |
| Gatilho               | Após o domínio confirmar que uma das duas peças acabou de entrar no lugar certo.                      |
| Duração e intensidade | Pulso dourado de até 420 ms; partículas finitas de até 420 ms.                                        |
| Foto protegida        | Não cobrir a peça, a face, as células vizinhas nem o texto de progresso.                              |
| Limite ativo          | Até oito faíscas totais para a troca e um som principal.                                              |
| Som                   | Papel acerto, sininho quente e curto; borda dourada é a alternativa visual.                           |
| Qualidade             | NORMAL mostra pulso e faíscas; LOW e reduzido mantêm borda e progresso sem partículas.                |
| Ciclo de vida         | A Scene é dona das faíscas, tweens e som; todos terminam ou são limpos em pause, saída e destruição.  |
| Teste de aceite       | Uma troca não recebe esse efeito quando apenas muda peças, sem aumentar posições corretas.            |

Referências de direção: Bíblia de movimento, Bíblia de áudio e dicionário de componentes.
