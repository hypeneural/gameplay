# Receita — troca sem solução

| Campo                 | Definição                                                                                                      |
| --------------------- | -------------------------------------------------------------------------------------------------------------- |
| Finalidade            | Mostrar que a troca aconteceu, mas ainda não resolveu uma posição, sem punição.                                |
| Planos de cena        | L2, somente nos dois contornos que acabaram de se acomodar.                                                    |
| Asset aprovado        | Áudio wrong já catalogado; nenhum asset visual adicional.                                                      |
| Gatilho               | Troca válida cuja contagem de peças no lugar não aumentou.                                                     |
| Duração e intensidade | Acomodação das peças de até 220 ms e retorno visual de até 160 ms.                                             |
| Foto protegida        | Sem tinta, tremor ou painel sobre a foto.                                                                      |
| Limite ativo          | Dois tweens de peças e, no máximo, um som curto.                                                               |
| Som                   | Papel tentativa sem avanço, mais baixo que acerto e sem timbre de alarme; a acomodação é a alternativa visual. |
| Qualidade             | Igual em NORMAL e LOW; reduzido usa acomodação direta e contraste.                                             |
| Ciclo de vida         | A Scene é dona das respostas; pause, saída e destruição cancelam o restante.                                   |
| Teste de aceite       | Uma troca não resolutiva continua compreensível e a próxima seleção funciona imediatamente após a acomodação.  |

Referências de direção: Bíblia de movimento e Bíblia de áudio.
