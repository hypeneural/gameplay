# Âncoras de estilo natalino

Esta pasta contém referências de direção de arte, não assets entregues pelo
navegador. Ela fica fora de `apps/play/public/`, não é listada no manifesto e
nunca contém foto de cliente.

## `master-style-frame-v1.png`

| Campo                        | Registro                                                                              |
| ---------------------------- | ------------------------------------------------------------------------------------- |
| Estado                       | candidata inicial para revisão do proprietário                                        |
| Finalidade                   | estabelecer hierarquia de cena para o Puzzle e jogos futuros                          |
| Direção                      | híbrida: cenário lúdico em planos + foto/moldura premium                              |
| Composição                   | retrato; área central protegida; azul-noturno, verde-pinho, framboesa e dourado suave |
| Conteúdo proibido respeitado | pessoas, rostos, foto real, texto, logotipo, marca e Papai Noel                       |
| Ferramenta                   | ImageGen integrada ao Codex, 2026-08-24                                               |
| Registro de origem           | metadados C2PA produzidos pela ferramenta; arquivo não é distribuído no jogo          |

A receita usada é a seção “Quadro mestre de estilo” em
[`../PROMPT_RECIPES.md`](../PROMPT_RECIPES.md), com a exigência adicional de
uma área central vazia e utilizável para foto. A decisão continua humana: esta
imagem só orienta etapas futuras depois de aprovação explícita do proprietário.

## Como revisar

1. Comparar a imagem em 390 px com uma foto real **somente no ambiente privado**.
2. Confirmar que a moldura e o cenário deixam a foto e o CTA mais fáceis de
   encontrar, em vez de decorarem a área central.
3. Rejeitar a referência se ela induzir arte genérica, objeto sobre rosto,
   excesso de dourado, luz néon ou cenário mais chamativo que a lembrança.
4. Não extrair, recortar ou publicar elementos desta referência como runtime
   sem uma nova etapa de preparação, proveniência e revisão.
